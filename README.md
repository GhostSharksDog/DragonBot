# 龙娘桌宠

Windows 透明桌宠，通过气泡聊天、提问和批准文件及 Chrome 操作。沿用本机 Codex 登录，聊天和设置保存在本机。

## 运行

0.6.0 安装包位于 `release/DragonPet-Setup-0.6.0.exe`。启动后显示角色和旁边的小聊天图标。点击图标打开输入气泡，单击角色查看或收起文字回复，双击查看 Codex 额度；右键角色或托盘图标进入完整对话、设置与授权范围、历史、暂停、隐藏和退出。单击角色会等待约300毫秒，以区分双击。

开发运行需要 Node.js 24、Codex CLI **0.160.1**：

```powershell
npm ci
npm run build
npm start
```

开发与测试命令：`npm run dev`、`npm test`、`npm run test:ui`、`npm run smoke`、`npm run package`、`npm run verify:package`。`dev` 会构建并打开程序；修改后重新运行。界面测试使用隔离的无头 Chrome 测试配置；打包验证只读取工具清单，不操作日常 Chrome。

若没有兼容的 Codex：`npm install -g @openai/codex@0.160.1`。程序优先解析 npm 安装中的原生 `codex.exe`，不通过 shell 调用启动脚本；也可在设置中填写兼容程序的完整路径。登录使用 Codex 官方流程，桌宠不读取或展示认证令牌。实际模型访问和额度取决于登录账号。

## 使用

1. 点击龙娘旁边的小聊天图标打开输入框。回复采用圆角矩形气泡，以简短文字为主；打开输入时会替换回复或额度气泡，同一时刻只显示一个气泡。需要执行任务时，右键打开“设置与授权范围”，选择本次任务可访问的文件夹，并填写长期允许的网站来源，如 `https://example.com`。Codex设置中可选择模型和该模型支持的推理强度，选择按模型保存。
2. 网页任务会自动启动独立 Chrome，无需扩展。也可在设置点击“显示浏览器”或“重新连接”。首次在独立窗口手动登录，之后保留该窗口的登录状态；日常 Chrome 的个人配置不会被接管。
3. 发送后切回文字回复；发送失败保留输入与草稿。追问选项显示在问题旁边，单击选择并进入下一题，最后统一提交；文字回答从聊天图标输入，可返回上一题修改。批准前展开查看具体操作、目标和影响，再选择“允许本次”“拒绝”或“停止任务”。
4. 点击其他位置收起小气泡，草稿和待回应请求保留；右键打开完整面板可查看长对话。可以补充要求或停止任务。新聊天、切换历史或重启会清空文件夹授权；网站和网页输入开关持续保存，可在设置移除。历史审批不会自动恢复。
5. 双击龙娘打开额度页，查看账号返回的剩余比例、窗口长度、重置时间及更新时间；可刷新或返回聊天。查看额度不创建任务，查询失败不会中断聊天。没有返回的数据会显示不可用，不换算成剩余对话次数。

普通任务通过受控文件工具执行，覆盖与删除需批准；删除送入回收站。项目任务可以使用原生命令与补丁，工作目录和写入范围限定在所选项目。构建、测试等标准命令沿用项目授权；扩大写入、网络、发布及其他原生审批进入同一队列。本机旧版 Windows 沙箱使用已确认的兼容模式，允许原生命令读取项目外文件，设置中可查看和关闭；关闭需要支持 MXC，否则命令无法启动。项目写入权限本身包含文件替换和删除能力，因此不要批准来源不明的构建脚本；受控删除及未获准的原生命令仍走审批。

网页支持页面读取、导航、标签页选择、输入、滚动与截图。已授权网站内普通链接可连续访问，按钮点击以及标记为提交、发送、支付等重要动作需明确批准。长期网页输入授权可能触发网站自动保存。嵌入式 iframe 内容暂不支持操作。网页任务只控制桌宠自己启动的 Chrome，不能提供任意网页脚本或其他应用操控。

## 继续开发项目

右键进入设置，在“项目接续”查找并选择已有桌宠开发对话，核对本地目录后保存。以后说“继续桌宠项目，……”会通过官方对话链接打开原对话，在核对过的输入区发送要求。该接续与桌宠自己的代码任务分开：原应用负责执行原对话，桌宠只跟踪消息和状态。

原对话忙碌时可等待或明确追加；有草稿时询问是否追加并一起发送。发送结果不明确时先核对，不自动重发。原应用中的审批必须在原应用处理。Windows 辅助功能组件目前针对 Codex 桌面应用的 ProseMirror 输入区；应用更新导致无法唯一识别时会停止并提示手动处理。

输入气泡空白或单行高约 88 像素，多行自动增高；额度气泡在加载和刷新时固定为约 340 像素。窗口收到当前视图的布局确认后才显示。选项不足以放在两侧时自动排到问题下方，选项间透明空隙允许穿透。

## 龙娘素材

未导入自定义角色时，程序自动载入内置银白龙娘。0.4.1 改用完整角色逐帧皮肤 `assets/skins/silver-dragon-frames`：待机依据用户指定的第一张图提取透明人物，思考使用已交付的完整角色序列，保留银白长发、龙角、紫眼、淡紫翅膀、白裙和鳞片尾巴。

本次实装待机和思考，每个动作24个播放帧、12fps、约2秒循环。思考含20个来源帧和4个正常持姿重复。回复、等待回答或审批等尚未制作的动作使用待机；同一实际动作的时钟保持连续。播放前预解码全套素材，状态更新不重新载入图片。

跑步手臂与步态继续制作，本次默认角色原地活动，仍可拖放与缩放。没有完整左右移动动作的皮肤暂停自动漫游，保留原漫游设置；带有左右走跑动作的导入皮肤继续支持横向移动和拖放后保持高度。

逐帧检查包位于 `release/animation-redraw-v1/`，原始生成图和提示保存在 `assets/animation-redraw-v1/`。旧包中的跑步只是候选，不代表本次已启用；实际默认素材以 `silver-dragon-frames/skin.json` 为准。旧版交互预览使用演示数据，不执行文件或网页操作。

素材仍支持透明单帧、网格图集及分层皮肤导入。素材无法载入时会显示临时龙蛋和错误提示。旧分层素材保留兼容，不再作为默认角色。

素材格式见 [角色素材说明](docs/skin-format.md)。

## 隐私与恢复

设置和聊天位于 Windows 的 `%APPDATA%/dragon-pet`；模型服务会处理你发送的消息及任务所需文件或网页内容。独立浏览器数据保存在该目录下的 `browser-profile`，其中包含网站登录状态；不复制日常 Chrome 的 Cookies。浏览器数据、项目发送状态、聊天、设置和登录数据不进入 Git 或安装包。

遇到断网、额度不足或后台退出时，气泡展示错误和重新连接入口。中断的网页变更不会自动重试，请先检查网页实际状态再继续。可以恢复聊天，但未完成操作与待批准请求不会在重启后重放。

Codex 接入使用本地 stdio 的 [app-server 协议](https://learn.chatgpt.com/docs/app-server)，目前锁定 0.160.1；升级协议前须重新生成类型并运行测试。程序只通过 app-server 执行自己创建的任务。接续其他客户端对话通过目标应用界面发送，随后只读核对记录，不从第二个后台恢复或驱动原对话。
