# 0.6.0：项目接续、独立浏览器与气泡布局

网页任务现在自动启动桌宠自己的 Chrome，通过本机私有管道连接，无需安装扩展。首次在独立窗口登录后保留登录状态；设置可显示浏览器或重新连接。日常 Chrome 配置不会被接管。支持读取、导航、标签页、中文输入、选择、滚动和截图；嵌入的 iframe 暂不支持。

设置新增长期项目关联。选择本地目录和已有开发对话后，“继续桌宠项目”会打开原应用对话并发送要求。忙碌和草稿冲突先询问，发送结果不明确时只核对、不重发；原应用审批仍由用户在原应用处理。桌宠自己的项目任务允许原生命令和代码修改，工作目录及写入范围使用当前项目。旧版 Windows 沙箱按用户确认使用项目外读取兼容模式，可在设置查看或关闭。

输入气泡空白与单行高约 88 像素，发送按钮距离底边约 15 像素；多行自动增高。额度加载和刷新共用 340 像素布局，当前视图确认布局后才显示。追问选项作为独立圆角气泡排列，空间不足时放在问题下方；单击作答、多题返回与提交去重共享现有请求队列。透明间隙允许鼠标穿透。

保留待机、思考素材、推理强度、长期网站授权、聊天记录和设置。

## 验证

- 自动测试：124 通过、1 项真实环境检查默认跳过；界面回归通过，包括左右/下方选项、键盘焦点、草稿及重复点击。
- 真实 Codex：提问、回答、创建隔离测试文件、运行构建与测试成功。
- 真实 Chrome：无需扩展、中文输入、拒绝提交后服务器未收到提交、登录 Cookie 跨重启保存、过期引用和越界网站被拒绝。
- 原应用接续：隔离验收对话收到且仅收到一条消息并返回最终回复；核对兼容输入区占位文字和消息末尾换行。
- 原生窗口：空白/单行/清空恢复 88 像素，多行增高；额度显示与刷新保持 340 像素，旧布局结果不覆盖新视图。

## 使用边界

项目原生写入权限包含替换和删除能力；标准构建脚本应来自可信项目。受控删除和未授权原生命令走真实审批。ChatGPT 桌面应用更新后若输入区或发送按钮无法唯一识别，接续会停止并提示手动处理。网页请求不会在响应丢失后自动重放。

构建与检查入口见 README；所有运行证据保存在被 Git 排除的 `.local` 目录，安装包在 `release`。
