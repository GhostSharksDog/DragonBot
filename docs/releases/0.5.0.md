# 0.5.0：椭圆气泡、推理强度和额度查询

小气泡使用椭圆和指向角色头部的尖角；透明区域允许鼠标穿透。单击聊天、双击查看Codex额度，拖动仍可移动角色。额度页与聊天共享草稿和待处理请求，不重复提交。

模型列表保留后台支持的推理档位，按模型保存选择；每一新轮任务显式传递推理强度。网站及网页输入开关在重启和切换会话后保存，文件夹继续按任务授权，已有重要操作审批保持有效。

额度查询读取Codex账号接口，显示窗口剩余比例与重置时间；缺失数据不当作零，过期缓存有标记。查询有独立超时、请求合并及账号切换保护，失败不会关闭聊天连接。

默认素材沿用0.4.1的完整人物待机和思考序列。升级保留用户聊天与设置；旧版已经清空的网站列表需重新添加一次。
