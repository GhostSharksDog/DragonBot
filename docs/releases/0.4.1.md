# 0.4.1：待机和思考实装

默认角色切换为完整人物逐帧动画，启用待机眨眼与轻微手部活动，以及抬手扶下巴、歪头思考。两套动作各24个播放帧，以12fps循环；思考如实保留20来源帧与4个持姿重复。

播放器提前解码素材，同一动作在流式回复、气泡开关和设置更新期间保持时钟。未提供的动作回到待机，透明区域命中继续使用同一裁切与姿态。

跑步手臂和步态尚在完善，本次默认角色保持原地活动，可自由拖放、缩放。无左右移动动作的皮肤暂停漫游；漫游偏好保留，导入完整走跑皮肤仍可恢复横向活动。聊天、登录、浏览器设置、任务权限和记录格式保持兼容。

内置素材来源、完整裁切与统一尺寸记录由 `scripts/create-frames-skin.mjs` 写入新皮肤目录。旧素材与此前检查包保留，不覆盖用户参考原图。
