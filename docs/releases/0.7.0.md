# 0.7.0 — 普通 Chat 与任务分流

普通问答、闲聊和改写使用独立 Chrome 中的 ChatGPT 普通“聊天”和 High。修改文件、运行项目、浏览器操作使用 Codex；继续桌宠项目仍发送至已关联的原应用对话。输入框支持自动、聊天、做事，自动分流不调用模型。

- Chat 使用独立账号登录目录、发送状态与本地历史；回复同步至小气泡，可停止。首次 Google 登录使用没有控制连接的普通 Chrome，用户手动关闭后再连接。不会在登录中途自动关窗。
- 每次发送前核对模式、实际可用模型和 High；不改用 Work、Codex 或收费 API。设置列出从账号界面读取的模型。
- 发送前保存请求，随后以网页消息编号和原文核对。断网、超时、登录失效和重启不自动重发；成功核对的回复恢复到本地历史。
- 复用专用标签，清理额外空白页与没有草稿、没有生成任务的旧 Chat 页。认证、草稿和生成中的页面保留。
- 保留 0.6.0 的项目权限、审批、独立网页浏览器、原对话接续、紧凑输入框、固定额度气泡和独立选择气泡。沿用待机、思考素材。

## 数据与限制

升级沿用原安装位置和用户数据。Codex 历史仍独立保存；旧消息按 Codex 处理。Chat 浏览器资料与历史只保存在 `%APPDATA%/dragon-pet/chat`，不进入仓库或安装包。

普通 Chat 的限制以账号和官方规则为准；禁用工具的 Codex 仍是 Codex，不作为普通聊天替代。页面布局变化时会停止并提示检查窗口。登录和敏感认证操作由用户完成；不复制 Cookie、不读取认证页面内容。

项目继续沿用已批准的 Windows 兼容模式：原生命令可读取项目外文件，项目写入范围保持原限制。现有素材中的跑步仍未实装，默认保持原地待机和思考。

## 验证

单元检查覆盖本地分流、上下文长度、独立消息来源、发送去重、草稿保护、错误模式和档位拒绝、断线恢复、网站设置保存，以及新版页面的段落读取与消息编号。真实账号已确认普通“聊天”、GPT-6、High；验收消息得到“气泡聊天成功”，中断后的结果只读核对恢复，没有重发。

完整界面回归覆盖气泡尺寸、选择与审批、中文输入、草稿保留、模型设置、额度与点击动作。发布检查另包含干净克隆构建、打包启动、安装后连接与原数据保留；真实账号检查须显式提供授权的用户数据目录，不在默认测试中自动执行。
