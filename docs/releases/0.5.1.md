# 0.5.1：圆角文字气泡与独立输入入口

日常回复采用浅色圆角矩形与指向角色的尖角，主要呈现文字。点击角色旁边的 30×26 聊天图标，打开独立输入气泡，同时替换任何回复、额度或完整面板。发送成功回到回复，失败保留草稿。

- 单击角色查看或收起回复，双击保留真实 Codex 额度入口，右键进入完整功能。
- 自动追问先显示文字，点击聊天图标后填写逐题答案；审批保留必要按钮与可展开的完整详情。
- 输入、回复、额度共用一个窗口，草稿、答案和提交锁在切换时保留；异步提交完成不会覆盖用户已切换的页面。
- 圆角轮廓、尖角和聊天图标的原生鼠标检测使用共享形状，透明边角允许穿透。
- 助手默认用中文普通文字简短回答，通常 1–3 句；用户要求的详情、必要结果和审批信息仍完整提供。

沿用已实装的待机与思考素材、模型推理强度选择及长期网站授权。设置和聊天记录保存在原有位置。

验证入口：`npm test`、`npm run test:ui`、`npm run verify:package`；`node scripts/verify-051-ui.mjs` 使用隔离设置检查打包版的输入入口和气泡切换，不发起推理任务。
