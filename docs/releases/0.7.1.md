# 0.7.1 — 气泡响应与额度布局

气泡曾在隐藏后等待动画帧再显示，Windows 上可累积为 2–3 秒。现在在布局提交后测量并确认尺寸，首次显示不等待隐藏窗口的绘制。保留布局编号校验、300 毫秒单双击判断、中文输入和草稿。

- 聊天图标直接打开输入，双击角色直接打开固定尺寸额度页；同一视图的内容更新不会重新隐藏窗口。
- 鼠标检测和动画状态读取不再复制整段历史，相同窗口布局不重复发布。
- Codex 已登录并连接成功后异步预读额度；打开复用 30 秒内未失效的缓存，过期则保留数据并后台更新。手动刷新始终请求最新数据，并发查询合并。
- 两秒后显示刷新较慢，十秒超时保留历史数字和重试入口；查询失败不终止任务。账号或连接变化清空缓存，旧响应不能覆盖新账号数据。
- 额度页没有纵向滚动条。类别左右切换，小屏每页一个额度窗口；点数、长名称和完整错误在详情中分页，缺失额度显示“—”。

## 验证

单元检查覆盖缓存期限、手动刷新、预读合并、慢请求和超时，以及既有账号切换、去重和任务隔离。界面检查覆盖 320×340、280×340 和 320×240 布局、完整错误分页、零额度、待处理请求、中文输入、草稿及角色动画。

`node scripts/verify-071-performance.mjs --executable <安装版路径> --long` 在隔离数据目录使用 1,000 条合成历史，检查隐藏 1、10、60 秒后的真实单击、双击和输入按钮，另验证固定额度布局。它不发送聊天、不创建任务。结果与预览写入 `.local/performance-071-*`。

设置环境变量 `DRAGON_PET_PERF=1` 可启用本地耗时记录，位置为用户数据目录下 `diagnostics/performance.json`。最多保留 256 条打开、布局、可见和额度请求事件，只有时间、固定阶段和耗时；不记录聊天、账号、令牌或网页内容。默认关闭，不上传。

## 升级

安装到原位置，保留设置、两个通道的聊天历史和浏览器登录数据。普通 Chat 和 Codex 的连接方式、权限及素材沿用 0.7.0。

## 安装版实测（2026-10-27）

原版隐藏后打开的对照样本为 2,037–3,029 毫秒。0.7.1 在本机正常负载、1,000 条合成历史下完成 36 次点击，包含隐藏 1、10、60 秒后打开：

| 操作 | P95 | 验收上限 |
| --- | ---: | ---: |
| 输入图标 | 112 毫秒 | 150 毫秒 |
| 双击查看额度（第二次点击后） | 59 毫秒 | 150 毫秒 |
| 单击角色（包含 300 毫秒判断） | 336 毫秒 | 450 毫秒 |

隐藏 60 秒后，以上三项分别为 38、29、328 毫秒。125%、150%、200% 缩放各补充 6 次点击，均通过；Windows 分数缩放的窗口尺寸允许 1 个逻辑像素取整差异。额度网络查询与窗口打开独立，默认缩放测试中的查询耗时为 496–746 毫秒，不能将窗口耗时理解为网络响应保证。

单元测试 140 通过、1 跳过；界面回归、安装包检查、干净克隆构建与测试通过。安装前后设置、聊天历史、浏览器登录文件及 Codex 配置校验一致。此次没有发送真实聊天或创建推理任务来测量界面速度。
