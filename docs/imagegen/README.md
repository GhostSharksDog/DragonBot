# 0.3.0 龙娘动画素材

身份依据是用户提供的三视图：`assets/reference/dragon-girl-three-view.png`。所有绘制、清理及补充姿势均由 **内置 imagegen** 生成，没有使用外部 API、CLI 或代码绘制角色。

最终素材为 12 个动作，每个动作包含 **24 个独立源帧，以 24 fps 播放**，共 288 个选中源帧。没有通过重复同一格、重复索引或只提高播放帧率来凑帧数。哈希查重确认的是图像独立性；动作含义、角色一致性和步态观感仍需视觉审核。

## 提示词与原图

- `prompt-set.json` 汇总 0.3 的公共身份描述、12 个动作的复现模板、精确提示词引用和最终所用 PNG 的 SHA-256、尺寸及字节数。公共/动作模板明确标为依据生成目标重构，不能当作原始调用逐字记录。
- `cleanup-prompts-24.json` 保存 running-left、awaiting-input、error 的清理提示词原文。
- `supplement-prompt-24.json` 保存三张向右跑姿势和一张等待回答姿势的补充提示词原文。
- `prompts.json` 是 0.2 三张四帧动作图集的历史提示词，保留用于追溯。

图像生成器没有总能遵守请求的网格与留白。实际输出包括 6×3、4×5、4×6、5×5 和 2×2；补充图的物理尺寸也与部分原图不同。程序采用测得的真实尺寸和独立主体轮廓，没有强行按请求中的网格线裁掉脚、尾巴或翅膀。

## 实际选材

具体文件和源帧索引以 `atlas-selection-24.json` 为准。待机、双向走跑优先选择清理后的版本；向右走保留轮廓完整的 v3。向右跑排除了 v4 中三个触及原图右边缘的姿势，由补充图替换。等待回答、等待批准和需要帮助动作使用与动作含义相符的补充姿势补齐。

`extras-24-v3.png` 中最右列上下两个人物粘连，不能当作一个可用姿势；该主体没有进入最终选择。真正触及原图边缘或与其他人物粘连的帧保持错误记录，没有为通过检查而删除错误。

## 轮廓、对齐与排序

`atlas-geometry-24.json` 记录全图连通主体检测、轮廓、查重及裁切验证。检测使用主体 alpha ≥ 96 的连通像素，忽略远处零散噪点。每个独立主体追踪凹轮廓并保留约 2 像素边缘余量；没有使用会吞入邻居尾巴的凸包。所选帧的检测主体像素保留率为 100%，轮廓内部的邻居主体像素数为 0。低 alpha 的边缘及原图边界另有警示，仍需视觉检查。

每个源姿势按比例显示在 512×512 逻辑画布中，脚底使用共同锚点。`outline` 通过 evenodd 轮廓显示裁切排除邻居；`frameSources` 与 `sourceSizes` 指向各张未经代码改写的原始 PNG。透明区域的鼠标检测使用相同几何。

这些数据只改变**运行时显示与命中检测**。检查程序只读取原图像素，轮廓追踪、特征分析和排序不切片、不重新编码、不覆盖任何 PNG。

四个走跑循环启用 `smooth-loop` 顺序：用归一化、轮廓内的 RGBA 特征计算差异，通过近邻与 2-opt 减少相邻帧及首尾接缝变化，并保持第一个姿势为起点。`atlas-sequence-review-24.json` 保留调整前后平均、最大和接缝差异及完整映射。该指标不代替步态视觉审核。success 始终保持原顺序且不循环，其他表情动作保留原顺序。

## 复核与生成元数据

```powershell
node scripts/inspect-atlases-24.mjs
node scripts/create-skin-manifest-24.mjs --selection docs/imagegen/atlas-selection-24.json --dry-run
```

确认源帧、轮廓与顺序后，移除 `--dry-run` 才会更新角色配置。检查支持 `--cuts` 提供真实网格或人工区域，选择配置支持来自多张图片的源帧。构建会拒绝所选坏帧、重复源帧和未验证轮廓；近似重复候选必须先视觉审核。

`tests/bundled-skin.test.ts` 只读检查最终配置、选材记录、几何证据、PNG 文件校验和与真实尺寸，不写入图片。
